barreplayrecord your games

Record your games

The Replay uploader widget records what you see during a live game into a .brepstream file. Upload it here and it becomes a replay anyone can watch.

1

Download the widget

Download replay_uploader.lua

If your browser opens the file instead of saving it, right-click the button and choose “Save link as…”.

2

Put it in your BAR installation

Save it as:

Beyond-All-Reason\data\LuaUI\Widgets\replay_uploader.lua

If the LuaUI\Widgets directories don’t exist — create them.

3

Enable it in game

Start any game. In game press F11, find Replay uploader on the list and click it to enable it.

4

Play, then upload

Play games, either as a spectator or a player. After each game you will find a .brepstream file inside Beyond-All-Reason\data. Upload that file.

Drop it on the dropzone at the top of the replay list. It is named after the game’s id, so the newest file is the game you just played.
